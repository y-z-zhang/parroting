# Analysis

Notebooks that aggregate saved benchmark statistics into the paper's figures,
plus the statistics they read and the figure PDFs they produce.

## Notebooks

| Notebook | Produces | Reads from |
|---|---|---|
| `analysis_fixed_context_length.ipynb` | Fig. 2 (`smape_rolling_compare_normalized.pdf`, `kl_compare.pdf`) and MSE/MAE/cdim companions | `../benchmark/benchmark_results/` (Fig. 2 models); `../benchmark/legacy/benchmark_results_old/` (panda/simplex/arima) |
| `analysis_vary_context_length.ipynb` | Context-length sweep figures (`vpt_vs_context_length_*.pdf`, `smape_rolling_D=10_normalized.pdf`, ...) | the `*_statistics_normalized/` and per-model `*_statistics/` directories here |

## Statistics directories

| Directory | Used by |
|---|---|
| `Chronos_statistics_normalized/`, `ChronosBolt_statistics_normalized/`, `TimeMoE_statistics_normalized/`, `TimesFM_statistics_normalized/`, `parrot_statistics_normalized/` | context-length sweep (`analysis_vary_context_length.ipynb`) |
| `Moirai_statistics/`, `arima_statistics/`, `dynamix_statistics/`, `panda_statistics/`, `simplex_statistics/` | context-length sweep; some also hold invariant-property files (`all_cdim_vary_context.npy`, ...) read by `../benchmark/benchmark_vary_context.ipynb` |
| `Chronos_statistics/`, `parrot_statistics/` | invariant-property sweeps in `../benchmark/benchmark_vary_context.ipynb` |
| `legacy/` | nothing — superseded data kept for provenance (see its README; note the sMAPE-scale warning) |

All sMAPE-derived numbers outside `legacy/` use the paper's 0-200 convention.

The loose `.npy`/`.pkl`/`.csv` files (`all_all_lyap_sweeping_*.npy`,
`all_hellinger_*.pkl`, `all_cdim_true_*.csv`, ...) are inputs/outputs of
`../benchmark/benchmark_vary_context.ipynb` and
`../benchmark/invariant_properties_longhorizons.ipynb`. The PDFs are figure
outputs regenerated by the notebooks listed above and by
`../benchmark/benchmark_long_rollouts.ipynb` (long-rollout forecast and power
spectrum panels).
